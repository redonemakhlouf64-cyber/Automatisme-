# Nyx Social Automation

A multi-platform social media automation and scheduling platform.

## Platforms

- Facebook
- Instagram
- Pinterest

## Core Features

- Multi-account management
- OAuth authentication
- Media library
- Image and video uploads
- Post composer
- Scheduling
- Queue processing
- Comments
- Automation rules
- Content recycling
- Gemini AI agent
- Analytics
- Calendar
- Android client
